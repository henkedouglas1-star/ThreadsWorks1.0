---

## 1. Purpose Of This Blueprint
This document is the canonical map for the Cash Machine curriculum and the architecture that will support its future AI implementation. It is intentionally a blueprint rather than a replacement for the original 1,749-page source. The original PDF remains the source of truth for source-derived material.
The Cash Machine is not simply 220 lessons. Its useful structure is knowledge + decision frameworks + exercises + diagnostics + content assets + operating procedures.

---

## 2. Product Architecture
* **Cash Machine Knowledge Layer:** Concepts, frameworks, lessons, exercises, decision rules, diagnostics, and outputs.
* **Cash Machine AI Intelligence Layer:** Interprets user context, diagnoses bottlenecks, selects relevant knowledge, and recommends the next best action.
* **User Business Context:** The user's offer, audience, positioning, acquisition, sales process, metrics, goals, and current situation.
* **Diagnosis:** Identifies the most important current bottleneck or opportunity.
* **Action:** Recommends the lesson, framework, exercise, or intervention most relevant to the diagnosis.
* **ThreadsWorks:** Executes the resulting content, messaging, campaigns, and other practical work.
* **Results & Metrics:** Feeds outcomes back into the intelligence layer for the next diagnosis.

---

## 3. Core Operating Loop
`Learn → Diagnose → Apply → Create → Execute → Measure → Improve`
`Knowledge → Intelligence → Action → Content → Conversations → Sales → Data → Intelligence`

*The deeper Cash Machine / ThreadsWorks loop is:*
`Knowledge → Intelligence → User Context → Diagnosis → Bottleneck / Opportunity → Next Best Action → Recommended Lesson → Exercise / Tool → Output → ThreadsWorks Execution → Results → New Diagnosis`
